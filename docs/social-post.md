I built ColdClock for the #AllThingsAgenticHackathon: an agent that starts where a refrigerator alarm stops. It assembles exact-quoted medicine and sensor evidence, waits for a named pharmacist decision, then coordinates a synthetic replacement through receipt. The failure demo matters most: missing evidence, reviewer failure, stock failure, and courier failure all stop safely—no invented disposition. Built on Cloud Run, live Gemini 3.5 Flash, Gemini Embedding 001, Firestore, privacy-safe action receipts, and Cloud Trace. https://cold-clock-109051079423.us-central1.run.app
