I built ColdClock for the #AllThingsAgenticHackathon: an agent that starts where a refrigerator alarm stops. It assembles exact-quoted medicine and sensor evidence, waits for a named pharmacist decision, coordinates a synthetic replacement — and then a Cloud Scheduler wake polls the courier at the ETA and closes the case while nobody is watching. Zero "continue" clicks, and the proof is derived from the persisted trace. The failure demo matters most: missing evidence, reviewer failure, stock failure, courier failure and injected package text all stop safely — no invented disposition. Built on Cloud Run, Firestore, Cloud Scheduler, live Gemini 3.5 Flash, Gemini Embedding 001, Gemma 4, and Cloud Trace. https://cold-clock-109051079423.us-central1.run.app
